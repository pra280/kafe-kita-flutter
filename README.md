# kafe-kita-flutter
Kafe Kita adalah aplikasi pemesanan menu kafe berbasis Flutter yang menyediakan berbagai pilihan makanan, minuman, dan dessert. Aplikasi ini dilengkapi fitur pencarian menu, kategori, detail produk, favorit, keranjang belanja, serta checkout dengan pilihan Dine In dan Take Away untuk memudahkan pelanggan melakukan pemesanan.
